## Findings considered and rejected (do not re-audit)

- **dailyGainers/dailyLosers "doc/code drift"**: not drift — both modules are
  deliberate deprecation stubs that always `throw` with a screener() migration
  message (`src/modules/dailyGainers.ts:79-85`). UPGRADING.md saying "removed"
  plus a helpful runtime error is coherent, intentional DX.
- **MCP `allowedHosts: []` disables host checks**: documented opt-out
  (`src/mcp/http.ts:14`), and the CLI refuses non-local binding without
  `--token` unless `--unsafe-no-token` is passed
  (`bin/yahoo-finance-mcp.ts:200-209`). By design.
- **Eager schema JSON imports (~640KB across modules)**: lazy-loading wouldn't
  shrink bundles (static imports either way), JSON parse cost is milliseconds,
  and size-sensitive users already have per-module subpath exports plus
  `createYahooFinance` composition. Not worth doing.
- **quoteCombine validates options on every call**: micro-optimization;
  validation of a small options object is microseconds. Not worth doing.
- **Rewrite `src/lib/validate/` on zod**: L effort, MED-HIGH risk on the core
  validation path, and the schema pipeline is JSON-Schema-based
  (ts-json-schema-generator) — zod would need a different generation pipeline.
  Speculative win; rejected for now.
- **CSV parser quoting/coercion bugs**: the entire CSV path is dead code —
  superseded by plan 006 (deletion).
- **CLI prototype-pollution via module dispatch**: module names are validated
  against an allowlist before dispatch; theoretical only.
- **CLI ANSI/terminal injection in output**: output goes through
  JSON-stringification which escapes control characters. No action.
- **Encrypt/keyring cookie storage**: disproportionate — the cookies are
  anonymous Yahoo consent/session cookies, no user login. Plan 007's 0600 file
  mode is the right-sized fix.
- **`.env.example`**: this is a library, not an app; the only env vars are
  test-infra (`FETCH_DEVEL*`), documented in CONTRIBUTING.md.
- **Codecov thresholds / pre-commit hooks**: maintainer-preference tooling with
  real false-positive costs; noted, not planned.
- **`@jest/types` + `jest-get-type` in a Deno repo**: used only for the
  `toBeType` test helper in `tests/common.ts`; harmless, tiny. Not worth a plan.
- **Fixture recache cron disabled**
  (`.github/workflows/recache-yahoo-fixtures.yaml`, commit `c2cc042` "disable
  cron for now"): known, deliberate maintainer decision awaiting rate-limit
  tuning. Surfaced as a reminder, not planned.
